How a record is created

  1. Buyer pays a live link on Offers, or a partner sends AFFILIATE: with a named domain.
  2. Matching subject hits the inbox. Full map on Contact.
  3. Agent reads the whole message. Ignores receipts that are not a Recursed SKU.
  4. If paid, fulfill the file. If unpaid, send the checkout. If traces are missing, ask for the packet — do not start the 48-hour clock.
  5. Append the stream log. Do not open a second thread. Mail steps are on Sequences.

What this page will not add

  • A public lead form that dumps into a shared spreadsheet.
  • A CRM product logo for a tool Recursed does not run.
  • Scoring, drip sequences, or a round-robin that assigns Jeff.
  • Catalog / Patreon / merch records. Those desks stay off this host.
